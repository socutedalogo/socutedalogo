### 🚨 Флагманский проект: Doomsday Dispatch
**Атмосферный ретро-симулятор диспетчера советского подземного бункера (1998 г.)**
* 🖥️ **Сеттинг:** Тоталитарный бункер на грани истощения. Вы - обычный диспетчер связи на старой ОС.
* ⚖️ **Геймплей:** Проверка депеш на фальсификации по приборам телеметрии, балансирование между приказами Госплана, требованиями рабочего подполья (КСР), взятками и спасением собственной семьи.
* 🔍 **Особенности:** Полная симуляция интерфейса Win95 / CRT-монитора, процедурные сбои, авторский саунд-дизайн и вариативные концовки.
